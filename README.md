# 🛕 Hidden Gems — Temple Info Website

Hidden Gems is a **bilingual web platform** that showcases lesser-known temples in and around Mangalore.  
The site helps visitors explore temple details, history, and locations with an easy-to-use interface.  

---

## 🚀 Features
- 📍 **Temple Information Pages** — history, details, and images of temples  
- 🌐 **Bilingual Support** — English + Kannada language toggle  
- 🗺 **Google Maps Integration** — for directions and navigation  
- 📱 **Responsive Design** — works across desktop and mobile devices  
- 🌟 **Lightweight & Fast** — built with simple frontend technologies  

---

## 🛠 Tech Stack
- **Languages:** HTML, CSS, JavaScript  
- **API:** Google Maps API  
- **Hosting:** GitHub Pages
